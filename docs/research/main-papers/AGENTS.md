# KB-Mixed 最小学习包

给完全不了解这套技术的人用的最小阅读集。六篇，四篇必读、两篇补充，全部为中文全译本 PDF（A4，可直接打印或平板批注）。

## KB是什么
教师先画一张标准答案（目标图），系统把它拆成概念卡与连接词卡，学生只能用这些零件重建；因为零件固定，系统能把学生的图与目标图做精确到连接一级的比对，差在哪、缺哪条，都能算出来，也能当堂反馈。KB-Mixed 在这之后再加一个开放式阶段：学生可以在重建的图上加目标图之外的概念与关系，用来看他能不能把知识往外推。
