# KB-Mixed 最小学习包
六篇 Kit-Build 论文的中文全译本，A4 版。四篇必读，两篇补充。全译本页数与论文原文页数不等，两个数分开记，不要当成同一个量。
@zone 标签表示写权限归属：user 表示只有用户可改，research 表示研究期可改。本文件只有一个 user 组。
## 用途
读 01 综述，用来判断本方法要解决什么教学问题、同行对它的批评落在哪。
读 02 框架，用来抄目标图到零件包到重建到诊断这条链条的判据。
读 03 KB-Mixed，用来分清 KB 与 KB-Mixed 的差别在重建之后的开放式阶段。
读 04 两阶段，用来定本项目的测量时点与结果报告口径。
读 05 效度，用来定自动打分与人工打分对照的方式，它对照了两种人工评分法。
读 06 代价，用来知道先给概念表会改变学生的连接选择与选词，属外部效度威胁。
## 方法是什么
教师画目标图。系统把目标图拆成概念卡与连接词卡，学生只能用这些零件重建。零件固定，故学生的图能与目标图逐条命题比对，算出缺哪条、多哪条、方向反了哪条，并可当堂反馈。
KB-Mixed 在重建之后加一个开放式外推阶段，允许学生加目标图之外的概念与关系，用来观察知识外推。本项目不采用这个阶段，只判封闭零件包内的重组，外推阶段只作文献背景读。
