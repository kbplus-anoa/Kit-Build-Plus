# src — 为什么
为什么引入这个功能。说不清就先别做。

## 问题

七个 feature 各自可测，但**没有一个能跑的入口**：学生与研究者只能用测试驱动。
同时，约定禁止 feature 互相 import，于是"谁把它们拼起来"没有归属——
若各处自行拼 `sys.path`，同一份装配逻辑会散落十几份，且彼此不一致。

## 目标

- 一个 HTTP 入口，把已有 feature 暴露成可调用的接口
- 一个装配层（`bootstrap`），集中决定"哪些表进同一个库""谁注入给谁"
- 参数与错误在边界处收口：feature 抛的领域异常映射成合适的状态码

## 不做什么

不含业务规则（评分、校验、判对都在 feature 里）、不直接写 SQL、
不做前端渲染。前端未开工。
