# ingest — 为什么
为什么引入这个功能。说不清就先别做。

## 问题

教材来源有三种：纯文本、epub、PDF。PDF 又分有文字层与扫描件。
三种输入的失败模式完全不同：网络与配额、压缩包结构、字体编码。
若合并进 `extract`，UIE 代码里会混进 PDF 解析与 HTTP 分支，
"扫描件下载失败"会表现为"抽取质量差"，无从定位。

## 目标

同一个出口：`ingest(path) -> TextDoc`。下游 `extract` 只面对纯文本，
并可从 `has_ocr` 得知"这段文本可能有识别错误"。

## 不做什么

不做分句、不做分词、不判定概念、不与数据库交互。
