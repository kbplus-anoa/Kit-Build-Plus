# quiz — 任务
一项一个可验证的完成态。用户授权前不勾选。

## 里程碑

- [ ] 契约 `Question` / `Answer` / `QuizRecord`，含三时点枚举与题型枚举
- [ ] 判对规则：未作答（-1）算错；规则只此一份，存储层复用
- [ ] 百分制 0–100：分母为题数，题数为 0 取 0.0
- [ ] 题套校验：选项数上下限、答案下标范围、题型合法、题干长度
- [ ] 整卷校验：关联键为正整数、时点一致、题号存在、同题不重复
- [ ] 题套落库：同一 `quiz_id` 内容不同则拒绝改写
- [ ] 逐题作答落库：同点同题可更新，不同时点互不覆盖
- [ ] 测验页：一屏一题、三时点复用同版式（**暂不实现 GUI**）
- [ ] 提交前未答清单与二次确认（**暂不实现 GUI**）
- [ ] 断线恢复已答题目（**暂不实现 GUI**）
