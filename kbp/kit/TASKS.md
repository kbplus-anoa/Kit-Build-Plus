# kit — 任务
一项一个可验证的完成态。用户授权前不勾选。

## 里程碑

- [ ] 裁定契约 `AdjudicationLog`：接受项与驳回项并存，理由留档
- [ ] **共用冻结规则**：概念去重编号、命题去重、去自环，两条路都调用它
- [ ] `freeze_auto`：直接从抽取结果冻结，不经人工裁定
- [ ] `freeze`：人工裁定路径，保留但只属开发期
- [ ] 内容指纹：概念集与命题集的稳定哈希，写入 `TargetMap`
- [ ] `split`：只保留被命题用到的概念与连接词
- [ ] `store`：裁定表 + 词表表；同批次不可覆盖，词表不可静默改写
- [ ] `lock`：已被学生用过即拒改（依赖注入的 `MapUsagePort`）
- [ ] `kit_service`：自动路与人工路各一条编排入口
- [ ] 自动路界面：三段进度与结论（**暂不实现 GUI**）
- [ ] 裁定页：键盘、批量、依据原文、冻结确认（**暂不实现 GUI**）
