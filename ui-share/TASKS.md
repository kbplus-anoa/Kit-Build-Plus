# ui-share — 任务
一项一个可验证的完成态。用户授权前不勾选。

> 本目录**不对应 Python 包**，留在仓库根：它是前端组件的共享层，
> 被 `web/` 里的多个页面复用。包化重构不改变它。

## 里程碑

- [ ] `styles/`：颜色、字号、间距、动效令牌（先定令牌，再写组件）
- [ ] `atoms/`：按钮、复选框、进度条、提示条
- [ ] `layout/`：顶栏、侧栏、底部操作条骨架
- [ ] `canvas/`：ReactFlow 封装、缩放平移、点-点连线（handle ≥ 24px）
- [ ] 无障碍基线：形状差异 + 文字标签，无红绿依赖
- [ ] 与 `web/` 的构建集成（Vite 别名或 monorepo 引用，方式待定）
